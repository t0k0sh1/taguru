## 1. Scope

A relation label, subject, object, or alias spelling that a
multilingual model writes with an ideograph from another language's
repertoire — simplified Chinese `适用法律` for a Japanese document
that says `適用法律` — and what `taguru extract`'s mechanical pass
does with it. Out of scope: any judgment of *which* language a
document is in (none is made); non-ideographic scripts (Hangul,
Cyrillic, Latin — nothing in the corpus called for a rule); a
translated or paraphrased label in the document's own characters
(vocabulary, ADR 0013 §3.1's ruling); and question text.

## 2. Context

The #780 baseline (qwen3:30b, Japanese law and minutes corpora) put
`前二項の罪 —[适用法律]→ 刑法第二条の例` in a batch: `适` is the
simplified form of `適`, appears nowhere in the document, and reads —
but as a *different string* from `適用法律`, so `query`, `resolve`,
and the label vocabulary all see two labels where the corpus has
one. A label is offered back to every later document of the run
(ADR 0014, #778), so one such spelling can seed more.

Measured over the three #780 runs (base, auto rung, 8 KB chunks;
2,813 labels and 5,272 subject/object names), two candidate rules:

- **"uses an ideograph the document does not contain"**: flags 94 of
  1,036 labels in the base run alone (9%) — `届出義務` for a document
  that never writes `義`, `適用対象` for one that never writes `象`
  — every one a normal Japanese compound the model chose as
  vocabulary. Useless as a rule: the document does not have to
  contain a label's characters, exactly as ADR 0013 §3.1 says.
- **"uses an ideograph outside JIS X 0208 that the document does not
  contain"**: flags 10 labels and 0 names — `处罚`, `导致`,
  `连带责任`, `适用法律`, `主张` (twice), `增加額` (twice), `定义`,
  `类型` — every one a simplified-Chinese spelling of a Japanese
  term. No false positive in 8,085 strings.

JIS X 0208 is the right repertoire for the second rule not because
the corpus is Japanese but because it is the one fixed, dictionary-
free, dependency-free set that separates "an ideograph Japanese text
uses" from "an ideograph only another language's orthography uses",
and the "not in the document" half of the rule makes it safe for a
Chinese or Korean document, or a Japanese one quoting either: there
every character the model uses is in the text.

The issue's second proposal was a corrective turn — "rewrite in the
document's characters" is present-but-wrong content, so it looked
correctable. Two facts decide against it. A Stage 1 issue the
corrective attempts leave standing fails the source (ADR 0022 §3
item 2 made only alias issues removable), so the corrective route
either risks a whole document for one label or needs a new
"removable after correction" class through the attempt loop; and the
model that wrote `适` is the one asked to fix it, at one completion
per affected piece, for a phenomenon measured at 0.36% of labels.

## 3. Decision

**In the Stage 1 mechanical pass, an association whose label,
subject, or object — or an alias whose spelling — contains a CJK
ideograph that is outside JIS X 0208's ideograph repertoire and does
not occur in the document text is removed, with ADR 0013's
accounting. Nothing is corrected, nothing is rewritten, and the rule
is not a fingerprint input.**

1. **The repertoire.** A CJK ideograph is a character in the Unified
   Ideographs block, its extension blocks, or the compatibility
   ideographs. The repertoire is the 6,356 ideographs of JIS X 0208
   (as Python's `shift_jis` codec encodes them — the table is
   generated by `scripts/gen_jis_x0208.py` into a 328-word bitset over
   U+4E00–U+9FFF and committed; every ideograph outside that block is
   outside the repertoire). Kana, punctuation, Latin, and every
   non-ideograph are not judged.
2. **The document side.** "Occurs in the document text" is character
   containment in the same haystack the occurrence check reads — the
   piece's text with its context block (ADR 0033 §3.6), whitespace-
   and case-folded as `normalize_for_occurrence` leaves ideographs
   untouched. A document that uses the character anywhere clears it
   for every label and name of that piece.
3. **The allowlist.** For a subject or object, ADR 0015's exemption
   applies exactly as it does for the occurrence check: a spelling
   the target context already uses is not judged. Labels have no
   allowlist (the reuse vocabulary is an offer, not a whitelist) and
   are always judged; an alias spelling likewise.
4. **Order in the pass.** After the single-character label rule and
   before the occurrence check; every offending field of an item is
   named in the one removal record (the occurrence check's own
   "both positions before anything is recorded" shape), so a label
   with `适` and an object with `处` read as one diagnosis:
   `associations[3]: label "适用法律" uses 适, object "处分" uses 处
   — ideographs outside the document's script`.
5. **Accounting**, ADR 0013 §3.4's unchanged: the stderr line
   path-first, the report line's `removed (mechanical validation)`
   count, `removed_items` on the diagnostics record, the trace's
   `loss` record (ADR 0024) with the item verbatim, and the
   checkpoint's `removed` list.
6. **Not a fingerprint input** (ADR 0036 §3.7): `PROMPT_VERSION`,
   manifests, and checkpoints are untouched; an already extracted
   document is not re-extracted, and a checkpointed unit is not
   re-judged.

## 4. Known limits, accepted

- **A traditional or variant form inside JIS X 0208 passes**: `辭任`
  for `辞任`, `其中` — JIS X 0208 carries the older forms, and the
  rule cannot tell a Chinese `辭` from a pre-war Japanese one. The
  corpus showed two such labels in 2,813; they remain vocabulary.
- **A Japanese document that is itself written in the other
  repertoire** — one quoting simplified Chinese at length — clears
  those characters for every label, by construction. That is the
  "not in the document" half doing its job; it is not tuned away.
- **Rare Japanese ideographs outside JIS X 0208** (`髙`, `﨑`, the
  JIS X 0213 additions) are judged as outside: a label or name using
  one is removed unless the document writes it — and a name the
  document does not write is what the occurrence check removes
  anyway. A corpus that trips on this would move the table to
  JIS X 0213 (`shift_jis_2004`), which the measurement showed also
  catches every corpus case except `增`.

## 5. Consequences

- **Behavior change, named in the changelog**: a strict-mode
  association or alias carrying a foreign-repertoire ideograph the
  document never writes is now removed with accounting where it was
  written into the batch. A run whose labels and names stay in the
  document's own characters sees no change.
- **The reuse vocabulary stays clean**: a removed label never enters
  the run's label counts, so it is never offered to a later document
  (#778's concern).
- **Tests** pin the rule: the ten corpus cases as a `removed/`
  fixture and a unit test per field (label, subject, object, alias);
  a document containing the character passing; the table's edges
  (`适` outside, `適` inside, U+4E00 and U+9FFF, an Extension A
  character outside); the ADR 0015 exemption for names; and the
  single-record diagnosis for an item offending in two fields.
- **SDK producers**: as ADR 0036 §5 — the LangChain producers have
  not adopted ADR 0013's mechanical pass; they adopt this rule with
  it.
